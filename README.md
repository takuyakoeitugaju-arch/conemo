# CONEMO 測定 入口ページ

コーチ用ページ（Google Apps Script）を、ブラウザの Google ログイン状態に関係なく開くための入口です。
このページ自体にはデータも合言葉も入っていません。中身は合言葉つきのリンクで開いたときだけ、スクリプトから読み込みます。

- `index.html`：入口。合言葉を `#` の後ろに移してから、スクリプトの中身を読み込んで表示する。速く見せるため、このスマホで前に開いた同じ画面をすぐ出し、裏で最新を取って、まだ触っていなければ差し替える。トップを開くと今日の8種目を裏で先読みする（10分に1回まで）。電波がないときは前の画面のまま（入力した数字はスマホに残り、電波が戻ると送られる）
- `sw.js`：電波がなくてもこのページ自体を開けるようにする（控えるのは `index.html` だけ。測定のデータには触らない）

- 変更が要るのは、スクリプトのウェブアプリ URL が変わったとき（「新しいデプロイ」を作ったとき）だけ。`index.html` の `var API = '…'` を書き換える
- スクリプトのコードを直して「デプロイを管理 → 新バージョン」をしただけなら、ここは触らなくてよい
- 前に開いた画面の控えは、そのスマホのブラウザにだけ残る（新しい順に24画面まで。印刷用の画面は控えない）
